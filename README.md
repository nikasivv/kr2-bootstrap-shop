# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию сайта интернет-магазина или каталога товаров, разработанную с использованием Bootstrap.

## Практическая работа 9

Выполнена главная страница на Bootstrap-сетке.

Реализовано:

- подключение Bootstrap через CDN;
- подключение `css/custom.css`;
- шапка страницы;
- Bootstrap-навигация;
- hero-блок на сетке;
- блок преимуществ;
- сетка популярных товаров;
- подвал страницы.

## Технологии

- HTML5
- CSS3
- Bootstrap 5.3.8
- JavaScript
- Git и GitHub Pages

Bootstrap хранится локально в папке `vendor/bootstrap`. Для подключения стилей и скриптов CDN не используется.

## Страницы

- `index.html` — главная страница, преимущества и популярные товары.
- `catalog.html` — каталог из шести товаров с фильтрацией и модальным окном.
- `product.html` — подробная информация о выбранном товаре.
- `order.html` — демонстрационная форма заказа.
- `contacts.html` — контакты и ответы на частые вопросы.

# FloraShop — цветочный магазин

## О проекте

FloraShop — учебный адаптивный сайт цветочного магазина, созданный с использованием HTML, CSS и Bootstrap 5.

## Самостоятельная доработка

- Добавлена дополнительная страница контактов.
- Каталог расширен до шести товаров.
- Добавлены категории и фильтрация товаров.
- Созданы разные варианты оформления карточек товаров.
- Добавлена карусель на главной странице.
- Добавлено модальное окно быстрого заказа.
- Добавлен аккордеон с часто задаваемыми вопросами.
- Добавлена форма заказа с проверкой обязательных полей.
- Добавлен выбор товара по параметру URL.
- Создана собственная таблица стилей `css/custom.css`.
- Добавлена адаптивная навигация Bootstrap.

## Запуск

Откройте `index.html` в браузере.

Для работы интерактивных компонентов должны быть доступны локальные файлы Bootstrap и `js/shop.js`.

## Ограничения

Форма заказа демонстрационная. Данные не отправляются на сервер и не сохраняются.
