# Контрольная работа №2 — FloraShop

**Тема:** «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

FloraShop — многостраничный учебный магазин букетов и комнатных растений. Интерфейс использует Bootstrap 5.3.8 и сохраняет цветовую систему проекта КР №1: ягодный акцент, светлый фон и тёмно-зелёный подвал. Визуальные изменения сделаны через `css/custom.css`, подключённый после Bootstrap.

## Страницы и сценарии

- `index.html` — адаптивное меню, hero-блок с каруселью, преимущества, сезонное предложение и популярные товары.
- `catalog.html` — шесть карточек, фильтры «Все товары», «Букеты», «Растения» и модальное окно быстрого заказа.
- `product.html` — карточка выбранного товара; товар передаётся параметром `?product=`.
- `order.html` — форма с проверкой имени, почты, телефона, товара и согласия; выбор товара передаётся из каталога.
- `contacts.html` — контактный блок, переходы к заказу и каталогу, ответы на частые вопросы в аккордеоне.

Форма демонстрационная: данные не отправляются на сервер и не сохраняются.

## Самостоятельные доработки

- Bootstrap подключён локально из `vendor/bootstrap/`, без CDN.
- Добавлена отдельная страница контактов и сквозной путь от карточки товара до заполненной формы.
- Каталог расширен до шести товаров и двух фильтруемых категорий.
- Добавлены дополнительные Bootstrap-компоненты: карусель, аккордеоны, модальное окно и уведомления.
- Карточки, цены, фильтры и форма оформлены в единой цветовой системе КР №1.
- На главной добавлен сезонный блок с переходом на выбранный товар.
- Настроены адаптивная сетка, мобильное меню, уменьшенные отступы на телефоне, видимый фокус и поддержка `prefers-reduced-motion`.

## Как проверить

1. Откройте `index.html` в браузере.
2. Проверьте меню и раскладку на ширине около 390 px, 768 px и 1280 px.
3. В каталоге переключите категории и откройте быстрый заказ у нескольких товаров.
4. Перейдите на карточку товара и нажмите «Заказать» — выбранный товар должен появиться в форме.
5. Отправьте пустую форму, затем заполненную: браузер должен проверить обязательные поля, а страница показать демонстрационное сообщение.
6. Проверьте аккордеоны на странице товара и контактов, а также переключение карусели на главной.

## Технологии

- HTML5 и CSS3;
- Bootstrap 5.3.8 (локальные CSS и JS Bundle);
- JavaScript для фильтрации, выбора товара и проверки формы;
- Git и GitHub Pages.

## Публикация

Репозиторий можно опубликовать через **Settings → Pages**. Форма остаётся учебной и не выполняет реальную отправку заказа.
